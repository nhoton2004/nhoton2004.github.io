Tool · Python + Excel

ChamCong — payroll from the fingerprint machine

The timeclock exports a nasty .xls; payroll was typed by hand every month. This reads the export, resolves each person's hours against a roster, writes the monthly sheet with openpyxl and produces a separate reconciliation report of the days a human should check. Delivered as a Windows .exe via PyInstaller.
